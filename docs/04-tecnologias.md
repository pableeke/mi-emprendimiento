# Tecnologías del proyecto — stayHard

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Construir la estructura y el diseño visual de todas las páginas del sitio (landing, tienda, blog y páginas legales), con diseño responsive. |
| Versionado | Git y GitHub | Guardar el historial de cambios del proyecto, trabajar de forma ordenada y respaldar el código en línea. |
| Publicación | GitHub Pages | Publicar el sitio en internet de forma gratuita para que pueda ser visto y evaluado mediante un enlace. |
| Diseño | Whimsical | Crear el mapa de sitio, los user flows y los wireframes de baja fidelidad antes de diseñar. |
| Diseño | Google Stitch | Generar y explorar propuestas de diseño de interfaz para las pantallas principales. |
| IA | Claude | Apoyar la redacción de contenidos, la estructuración de los documentos del proyecto y la revisión del código. |
| Editor | Visual Studio Code | Escribir y editar el código HTML y CSS, con extensiones como Live Server para ver los cambios en tiempo real. |

## Integraciones para una versión real

- Pasarela de pago chilena (Webpay, Flow o Mercado Pago) para cobrar los planes en línea.
- Backend o base de datos para guardar los formularios de diagnóstico, los pedidos y los datos de los clientes.
- Servicio de correo y automatización (por ejemplo, Mailchimp o Brevo) para la suscripción, la confirmación de compra y el envío de los planes.
- WhatsApp Business para atender consultas y dar seguimiento a los clientes.
- Sistema de agenda (por ejemplo, Calendly) para las videollamadas de evaluación inicial.
- Sistema de comentarios y gestor de contenidos (CMS) para administrar el blog.
- Google Analytics para medir visitas, conversiones y comportamiento de los usuarios.
- Área de cliente para entregar el plan en formato digital y registrar el progreso.

## Restricciones

- **Plazo:** [completar con la fecha de entrega indicada en la asignatura].
- **Marca:** stayHard es una marca nueva, sin identidad gráfica previa. El logotipo, la paleta de colores y la tipografía se definen durante el proyecto, con una imagen deportiva, motivadora y profesional. No se usan fotografías de marcas deportivas registradas.
- **Dispositivos:** el sitio debe verse y funcionar bien en celular, tablet y computador, priorizando el celular (enfoque mobile-first), ya que la mayoría de los deportistas navega desde el teléfono.
